# Como comecei meu arquivo pessoal

Hoje decidi criar meu canto na internet.

Não é apenas um blog. É um arquivo pessoal das coisas que estou aprendendo, construindo e tentando entender.

## Por que um arquivo pessoal?

Porque quero ter um lugar onde documentar:

- O que estou estudando na faculdade
- Projetos que estou desenvolvendo
- Coisas que aprendi sobre programação e Linux
- Ideias que quero desenvolver
- Experiências que quero lembrar

## Como funciona

O site é feito com Astro e hospedado no GitHub Pages.

Todo o conteúdo vive como arquivos Markdown versionados no Git.

Isso significa que:

1. Meus textos têm histórico completo de alterações
2. O conteúdo é portável — posso trocar de framework sem perder nada
3. Tudo é open source e transparente

## O que vem pela frente

Escrever mais. Aprender mais. Documentar mais.

Esse é o começo.
